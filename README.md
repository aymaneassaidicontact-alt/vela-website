# VELA — VELORANTIS INTERNATIONAL TECHNOLOGIES (Updated Edition)

## ما تم إضافته وتحديثه في هذه النسخة:
1. **قصة البداية والمؤسس (Aymane Assaidi):** إبراز رحلة أيمن كطالب شغوف بالبرمجة وكيف حول شغفه إلى شركة تقنية متكاملة برؤية هندسية دقيقة.
2. **نظام العمل والعمليات الحية (Live Operations Command Center):** لوحة تفاعلية تحاكي فرق العمل الهندسية الأربعة (Pods) وشريط تحديثات حي (Live Telemetry).
3. **معرض صور الشركة والفريق:** صور احترافية تعبر عن البرمجة، العمل الجماعي، والمقر التنفيذي.
4. **خريطة الشركة والتواجد الجغرافي:** توضيح المقر الرئيسي في الناظور (المغرب) ونقاط التوسع في أوروبا والشرق الأوسط.
5. **طموحاتنا المستقبلية (Horizon 2030):** استعراض رؤية الشركة في الذكاء الاصطناعي السيادي، بناء الشركات الناشئة، وتمكين الشباب.
6. **دعم كامل للغتين العربية والإنجليزية (AR / EN):** جميع الأقسام الجديدة مترجمة بالكامل وتعمل بسلاسة مع زر تبديل اللغة.

2. افتح ملف `index.html` مباشرة في المتصفح.
